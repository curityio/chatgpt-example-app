# Simple Consentor Plugin

The example deployment uses a BankID signing consentor after step-up authentication, to get a high privilege access token.\
By default, all clients on the profile that activate user consent must then use the BankID signing consentor.

This plugin shows how other clients on the profile can instead use a custom consentor, to replace the built-in consent form.\
The example deployment uses the simple consentor after the initial user authentication flow.
